# mcc-ps2

An unofficial, open-source reimplementation of Minecraft from the classic/indev era for the Sony PlayStation 2.

The project aims to recreate the functionality and behaviour of the original game as an independently implemented PlayStation 2 program written in C.

## Legal

This repository does not contain or distribute Minecraft, or Mojang intellectual property.

Any assets required for this port to function correctly must be supplied by the user from a copy of the game they are legally entitled to use.

## Reverse Engineering and Interoperability

This project involves studying and reverse engineering the original Minecraft Java program using tools such as Ghidra.

This process is used to understand the original program's behaviour and technical implementation, enabling core mechanics such as player movement and terrain generation to be independently reimplemented in C for the PlayStation 2.

The resulting implementation is written independently and does not contain copied Minecraft source code.
